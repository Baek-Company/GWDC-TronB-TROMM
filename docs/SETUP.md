## 사용자님이 필요한 단계

1. **TronLink 설치 권한:** 공식 사이트에서 Chrome 웹 스토어의 Helix Tech Company Limited 배포본까지 확인했습니다. 설치 창은 모든 웹사이트 데이터 읽기·변경과 클립보드 수정 권한을 요청합니다. 이 권한 확인 답변을 기다리고 있어 확장 프로그램 설치는 아직 완료되지 않았습니다.
2. **개발 지갑 생성:** 설치 후 사용자님이 직접 비밀번호를 설정하고 복구 구문을 보관해야 합니다. 비밀번호/복구 구문을 이 프로젝트나 채팅에 전달하지 않습니다.
3. **Nile 테스트 토큰:** 개발 지갑에서 Nile 선택 → 공개 주소 복사 → 공식 Faucet에서 테스트 토큰 요청. 지갑 생성 전이므로 아직 수행하지 않았습니다.
