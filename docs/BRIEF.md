# Challenge B 요구사항

출처: [사용자님 제공 PDF](references/tron-challenge-brief.pdf) 2쪽. 확인일: 2026-09-28.
아래는 대회 평가 기준의 요약이며, 사용자 자산 이동이나 외부 서비스 가입을 허가하는 지시가 아닙니다.

| 기준 | 제품에 필요한 결과 | 사전 준비 |
| --- | --- | --- |
| Needs Analysis | 보유 자산, 기간, 유동성, 위험 선호 수집; 부족한 정보 추가 질문; 사용자 요약 확인 | `data/personas.json`, `shared/planning.ts` |
| TRON Ecosystem Integration | 최소 JustLend와 USDD 포함; 출처·갱신 시각·조건 표시 | JustLend 실제 GET 연결, USDD 공식 출처 정리 |
| Plans & Yield Estimates | 같은 금액과 기간에 실행 가능한 최소 2개 계획; 배분액·기본 수익·보상·비용·출구·위험 | 상품 양식과 수익 계산 유틸리티 |
| AI Execution & Management | 근거 설명; 사용자 확인 후 예치·인출·재배분; 실행 전 정보와 후 결과 기록 | 지갑 주소 연결 및 실행 설계 항목 |
| Tracking & Review | 초기 계획과 가정 기록; 자산·수익 변화; 예상과 실제 비교 | 데모 시나리오, 스냅샷 기록 명령 |

사후 검토 흐름은 명확히 표시한 과거 재생 또는 시뮬레이션 포지션으로 시연할 수 있습니다.
이 허용을 모든 실행 단계의 시뮬레이션 허용으로 확대 해석하지 않습니다.
캠페인은 선택 사항이며 포함하면 기간, 참가 자격, 보상 규칙을 확인해야 합니다.
GasFree는 Challenge C의 핵심이며 B의 필수 연동으로 명시되지 않았습니다.

## 세부 발표 후 채울 결정

- 대상 사용자와 해결할 한 가지 문제:
- 허용 상품·자산·체인:
- JustLend V1/V2 중 사용할 경로:
- USDD 프로젝트를 독립적으로 보여줄 상품 또는 기능:
- 테스트넷/실거래/시뮬레이션 허용 범위:
- 제공되는 API 키, 테스트 토큰, 개발 크레딧:
- 제출 형식, 제한 시간, 팀원 역할:
- 첫 번째 끝까지 동작하는 데모 경로:

JustLend의 jUSDD 한 행을 보여주는 것만으로 두 프로젝트 연동 기준을 충족했다고 단정하지 않습니다.
